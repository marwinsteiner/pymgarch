# Example data

`dji30ret_5.csv` contains daily log returns (in percent) of five Dow Jones
constituents (AA, AXP, BA, BAC, C), 1,000 trading days starting 1987-03-16.
It is the first five columns of the `dji30ret` dataset distributed with the
R package rmgarch, scaled by 100 -- the same extract the replication test
fixtures are generated from.
